# PHASE 3: ASYMMETRIC CORE WIDTHS & KOGELNIK DETUNING MODELS

## Overview
Phase 3 investigated asymmetric directional coupler geometries where Waveguide 2 was given a different physical width (e.g., w2 = 220 nm, 280 nm, 340 nm) to introduce an intrinsic geometric phase mismatch (Delta_beta) to suppress cross-coupling in the crystalline state.

## Key Outcomes & Why Abandoned
* **Cross-State Degradation:** While intentional width asymmetry improved crystalline bar retention, it broke the synchronous phase-matching condition in the amorphous state. Maximum cross transfer was capped at ~90-92%, failing the > 98% single-port target.
* **Lithographic Sensitivity:** Tight control of two different sub-wavelength waveguide widths across a 100 nm gap created high sensitivity to etching tolerances.
* **Conclusion:** Symmetric waveguides with identical amorphous stacks (Delta_beta = 0 in State 0) are mandatory for near-100% cross transfer.
